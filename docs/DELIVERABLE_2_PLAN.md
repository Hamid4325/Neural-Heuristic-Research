### 3.2 Search contract — `src/search.py`

```python
from dataclasses import dataclass
from typing import Callable
import numpy as np

@dataclass
class SearchResult:
    found: bool
    path: list[tuple[int, int]]
    cost: float
    nodes_expanded: int
    nodes_generated: int
    heuristic_calls: int
    runtime_ms: float
    peak_open: int

def astar(
    grid: np.ndarray,
    start: tuple[int, int],
    goal: tuple[int, int],
    heuristic: Callable[[int, int], float],
    tie_break: str = "h",
) -> SearchResult:
    ...
```

Requirements:

- 4-connected grid, uniform move cost `1.0`.
- Walls are `1`, free cells are `0`.
- Deterministic tie-breaking with a monotonically increasing counter.
- `nodes_expanded` counts nodes popped and closed exactly once.
- `nodes_generated` counts nodes pushed onto the open set.
- `runtime_ms` uses `time.perf_counter()`.
- Return `found=False` and `cost=float("inf")` if no path exists.
- Return `cost=0` and a single-cell path when `start == goal`.

### 3.3 Heuristic contract — `src/heuristics.py`

```python
from typing import Protocol

class Heuristic(Protocol):
    name: str
    def __call__(self, r: int, c: int) -> float:
        ...

class ManhattanHeuristic:
    name: str = "manhattan"
    def __init__(self, goal: tuple[int, int]): ...
    def __call__(self, r: int, c: int) -> float: ...

class OracleHeuristic:
    name: str = "oracle"
    def __init__(self, h_star: "np.ndarray"): ...
    def __call__(self, r: int, c: int) -> float: ...

class NeuralHeuristic:
    name: str = "neural"
    def __init__(
        self,
        checkpoint_path: str,
        grid: "np.ndarray",
        goal: tuple[int, int],
        alpha: float = 1.0,
        mode: str = "raw",          # raw | scaled | clipped_manhattan
        batch_size: int = 8192,
    ): ...
    def __call__(self, r: int, c: int) -> float: ...
```

`NeuralHeuristic` must:

- Build the same 29 features used during training.
- Predict for all free cells once per maze, in batches.
- Denormalise with the checkpoint's `target_mean` and `target_std`.
- Clamp predictions to `>= 0`.
- Apply `mode`:
  - `raw`: return the clamped prediction.
  - `scaled`: return `alpha * prediction`.
  - `clipped_manhattan`: return `min(alpha * prediction, manhattan)`.
- Return the Manhattan value for walls, out-of-bounds cells, or invalid cells.

**Task 5.1.1 — Implement A***

Create `src/search.py` following the contract in Section 3.2.

Implementation notes:

- Use `heapq`.
- Heap entries: `(f, h, counter, r, c)` or `(f, counter, r, c)`.
- Keep a 2D `g_score` array initialised to `inf`.
- Keep a `closed` boolean array.
- Keep `parent` as a dict or 2D array of tuples.
- Only expand cells inside the grid and free (`grid[r, c] == 0`).
- Count a node as expanded when it is popped and not already closed.
- Reconstruct the path by walking `parent` from the goal.

**Tests for A*:**

```python
def test_empty_grid_optimal_cost():
    grid = np.zeros((3, 3), dtype=np.uint8)
    result = astar(grid, (0, 0), (2, 2), ManhattanHeuristic((2, 2)))
    assert result.found
    assert result.cost == 4.0
    assert result.path[0] == (0, 0)
    assert result.path[-1] == (2, 2)

def test_blocked_grid_returns_not_found():
    grid = np.ones((3, 3), dtype=np.uint8)
    grid[0, 0] = 0
    result = astar(grid, (0, 0), (2, 2), ManhattanHeuristic((2, 2)))
    assert not result.found
    assert result.cost == float("inf")

def test_start_equals_goal():
    grid = np.zeros((3, 3), dtype=np.uint8)
    result = astar(grid, (1, 1), (1, 1), ManhattanHeuristic((1, 1)))
    assert result.found
    assert result.cost == 0.0
    assert result.path == [(1, 1)]

def test_deterministic_node_counts():
    grid = np.zeros((5, 5), dtype=np.uint8)
    r1 = astar(grid, (0, 0), (4, 4), ManhattanHeuristic((4, 4)))
    r2 = astar(grid, (0, 0), (4, 4), ManhattanHeuristic((4, 4)))
    assert r1.nodes_expanded == r2.nodes_expanded
    assert r1.nodes_generated == r2.nodes_generated
```

Add an oracle test using a small handcrafted `h_star` array:

```python
def test_oracle_never_expands_more_than_manhattan():
    grid = np.zeros((5, 5), dtype=np.uint8)
    # h_star is Manhattan on an empty grid
    h_star = np.add.outer(np.arange(5), np.arange(5)).astype(np.float32)
    h_star = np.abs(np.arange(5)[:, None] - 4) + np.abs(np.arange(5)[None, :] - 4)
    oracle = OracleHeuristic(h_star)
    r_oracle = astar(grid, (0, 0), (4, 4), oracle)
    r_manhattan = astar(grid, (0, 0), (4, 4), ManhattanHeuristic((4, 4)))
    assert r_oracle.nodes_expanded <= r_manhattan.nodes_expanded
```

## 10. Shared evaluation protocol

### 10.1 Validation strategy

Use the existing **70/15/15 split by maze**:

```text
train: 1,313 mazes / 4,407,160 cells
val:     281 mazes /   896,328 cells
test:    282 mazes /   911,949 cells
```

Justify in the report that the split is by maze, so no topology appears in more than one
split. A clear holdout split is accepted by the rubric; K-fold is not used because of CPU
cost. The test set is used only after the final configuration is frozen.

### 10.2 Regression metrics

- MSE, RMSE, MAE on `h*/N` and in cells (multiply by grid size).
- R², Pearson, Spearman.
- Mean signed error (bias).
- p95, p99, max absolute error.
- Admissibility:
  - Fraction of reachable cells with `h_theta > h_star + 0.5` cell.
  - Mean, p95, max overestimation in cells.

### 10.3 Classification metrics

The auxiliary 10-bin head provides:

- Per-bin precision, recall, F1.
- Macro and weighted averages.
- One-vs-rest macro AUC-ROC and per-bin AUC.
- Confusion matrix.
- Top-1 bin accuracy.

Justification for the report:

- The primary task is regression, so plain accuracy is inappropriate.
- Distance-bin classification measures whether the model captures the correct cost regime.
- Bins are imbalanced, so macro-F1 and per-bin recall are reported alongside weighted
  averages.
- AUC-ROC is threshold-independent and appropriate for imbalanced bins.
- A second classification view is **expansion agreement**: precision, recall, and F1
  between the sets of nodes expanded by neural A* and oracle A*.

### 10.4 Search metrics

For every test maze and heuristic:

- Nodes expanded.
- Nodes generated.
- Path cost.
- Optimality ratio `cost / opt_cost`.
- Runtime in milliseconds.
- Heuristic calls.
- Peak open-set size.
- Success rate.
- Relative node reduction vs Manhattan.

Heuristics:

- Dijkstra (`h = 0`).
- Manhattan.
- Oracle (`h*`).
- Neural raw.
- Neural scaled with `alpha in {0.6, 0.7, 0.8, 0.9, 1.0}`.
- Neural `clipped_manhattan` at the best alpha.

Statistical test:

- Paired Wilcoxon signed-rank test on nodes expanded, neural vs Manhattan.
- Report p-value and effect size.

### 10.5 Error analysis

- Predicted vs true scatter.
- Residual histogram.
- Error by distance-to-goal decile.
- Error by local wall density.
- Worst mazes by RMSE and by node-expansion regression.
- Visual `h*` vs `h_theta` vs Manhattan on sample mazes.
- Cases where neural A* expands more nodes than Manhattan.

### 10.6 Bias check

There are no demographic attributes in a synthetic maze dataset. Define environmental
subgroups instead:

- Generator: backtracker vs Perlin.
- Grid size: 20, 40, 60, 80, 100.
- Obstacle density: 10, 20, 30, 40%.
- Distance-to-goal decile.

## Appendix A — Deterministic split reconstruction snippet

Use this if `data/processed/split_manifest.json` is not available.

```python
import glob
import os
import numpy as np

def reconstruct_split(cleaned_dir="data/cleaned", seed=42):
    files = sorted(glob.glob(os.path.join(cleaned_dir, "*.npz")))
    if not files:
        raise SystemExit(f"No .npz files in {cleaned_dir}. Regenerate the dataset first.")

    total = 0
    for f in files:
        with np.load(f) as d:
            total += len(d["grids"])

    rng = np.random.default_rng(seed)
    shuffled = rng.permutation(total)
    n_train = int(round(0.70 * total))
    n_val = int(round(0.15 * total))

    assignment = np.empty(total, dtype=object)
    assignment[shuffled[:n_train]] = "train"
    assignment[shuffled[n_train:n_train + n_val]] = "val"
    assignment[shuffled[n_train + n_val:]] = "test"

    return files, assignment


def iter_split_mazes(files, assignment, split):
    gid = 0
    for path in files:
        with np.load(path) as d:
            grids = d["grids"]
            starts = d["starts"]
            goals = d["goals"]
            h_star = d["h_star"]
            opt_cost = d["opt_cost"]
            for i in range(len(grids)):
                if assignment[gid] == split:
                    yield {
                        "file_name": os.path.basename(path),
                        "local_index": i,
                        "grid": grids[i],
                        "start": tuple(int(v) for v in starts[i]),
                        "goal": tuple(int(v) for v in goals[i]),
                        "h_star": h_star[i],
                        "opt_cost": float(opt_cost[i]),
                    }
                gid += 1
```

does not require PyTorch.

```python
import joblib
import numpy as np
from sklearn.neural_network import MLPClassifier, MLPRegressor

train = np.load("data/processed/train.npz")
X, y = train["X"], train["y"]

rng = np.random.default_rng(42)
idx = rng.choice(len(X), size=min(100_000, len(X)), replace=False)
X, y = X[idx], y[idx]

# Regression: predict h*/N
reg = MLPRegressor(
    hidden_layer_sizes=(64, 64),
    max_iter=100,
    random_state=42,
    verbose=True,
)
reg.fit(X, y)
joblib.dump(reg, "models/fallback_mlp_regressor.joblib")

# Classification: 10 distance bins
edges = np.quantile(y, np.linspace(0, 1, 11)[1:-1])
bins = np.digitize(y, edges)
clf = MLPClassifier(
    hidden_layer_sizes=(64, 64),
    max_iter=100,
    random_state=42,
    verbose=True,
)
clf.fit(X, bins)
joblib.dump({"model": clf, "bin_edges": edges}, "models/fallback_mlp_classifier.joblib")
```

If training is slow on your machine, reduce the sample to 50,000 cells and/or use
`hidden_layer_sizes=(32, 32)`.

        # Predict, denormalise, clamp, and return an (N, N) array.
        ...

    def __call__(self, r, c):

            return max(0.0, float(self._pred[r, c]))
        if self.mode == "scaled":
